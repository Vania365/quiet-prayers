# Quiet Prayers (native wrapper)

Capacitor project for the Quiet Prayers app (`com.quietprayers.daily`).

- `www/` = the web app, copied from `../quiet_prayers_app` with `npm run web` (commit it after every change).
- `android/`, `ios/` = native projects generated by Capacitor.
- `docs/` = public pages served by GitHub Pages (privacy policy + support).
- `codemagic.yaml` = cloud build workflows (Android test APK, Android release AAB, iOS).

Build in the cloud: see `CLOUD_BUILD_STEPS.md` (Hebrew, step by step).
